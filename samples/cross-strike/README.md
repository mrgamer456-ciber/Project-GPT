# Cross Strike — arquivos de teste

Esta pasta é destinada à análise técnica de amostras de arquivos `.pak` do Cross Strike.

## Como adicionar amostras

- Envie aqui apenas arquivos que você tem autorização para compartilhar.
- Não publique conteúdo protegido por direitos autorais ou arquivos extraídos de jogos sem permissão.
- Se não puder compartilhar os arquivos, envie somente informações técnicas (nomes, tamanhos e hashes) ou uma amostra própria e pequena.

As análises devem identificar estrutura, cabeçalhos, tabelas e formatos sem redistribuir conteúdo protegido.
