# CrossStrike — texturas originais para edição

Esta pasta recebe cópias planas das 382 texturas PNG extraídas dos arquivos TEXR, sem brilho ou alteração artificial de cores.

Os nomes começam com a área de origem: COMMON, FLAT, ISLAND, KASBAH, OFFSHORE, SNOWFIELD ou TRAINING.

Execute o workflow **Extract every CrossStrike TEXR texture** para preencher esta pasta com as imagens.
